Learning Steps: 
1.	Step 1: I began by learning the fundamentals of GitHub—repositories, commits, branches, and version control. Introductory tutorials like “Git and GitHub for Beginners” helped me grasp how developers use the platform to track and share code. I created an account, explored the interface, and familiarized myself with basic repository setup.
2.	Step 2: Next, I moved into hands-on practice using Git commands in the terminal. I learned to initialize repositories, stage and commit changes, and push updates to GitHub. I also cloned repositories and experimented with branching. These exercises helped me connect the theory to real workflows and understand how local and remote repositories interact.
3.	Step 3: Once comfortable with the basics, I explored collaboration features like pull requests, forking, and merging branches. Using the GitHub Guides and additional tutorials, I practiced resolving merge conflicts and managing contributions. I also looked into GitHub Issues and Actions to see how they support teamwork and automation. 
4.	Step 4: To put everything into practice, I built a small project and uploaded it to a new GitHub repository. I wrote a clear README, tracked changes, and used version control throughout the process. This final step reinforced my learning and gave me a concrete example of how GitHub supports professional project management and collaboration.
